Privacy policy

Last updated: 9 October 2026

The Mr. Knowledge analytics tool is a private tool used only by the owner of the Mr. Knowledge YouTube channel. It is not offered to anyone else.

What it accesses

With the channel owner's permission (Google OAuth, read-only scopes), it reads YouTube Analytics and YouTube Data for the owner's own channel: per-video views, watch time, average percentage viewed, audience retention and subscribers gained.

How the data is used

Only to decide how future videos on the channel are made (topics, titles, thumbnails and pacing). Aggregate numbers are stored in the channel's private code repository.

What it does not do

It does not access data about viewers as individuals, does not sell or share data with anyone, does not use it for advertising, and does not post, edit or delete anything on YouTube.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses the YouTube API Services; see also the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
